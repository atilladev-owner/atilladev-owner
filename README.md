## How I build

**Build it.** Products owned end to end: interface, architecture, database and deployment.<br>
**Break it.** Concurrency, authorization boundaries, duplicate payments and recovery paths get attacked before release.<br>
**Prove it.** Tests run against a real database, and the result is checked against what the system has to do.
